The <a href="https://marketplace.atlassian.com/1222421" target="_blank">ConfigCat Feature Flags Jira Cloud App</a> allows you to connect your Jira Issues and feature flags. Create or link existing flags to your Jira issues without leaving your Jira instance.

Turn features On/Off right from a linked Issue on your Jira board. You can also easily modify the linked flags to edit or add new Targeting or Percentage Rules.

This guide will help you with the app installation and familiarise you with the app usage.

:::info
This integration is for Jira Cloud. It does not work on Jira Data Center or Jira Server instances.
:::

## Migration to Jira Forge
Atlassian ends support for the Jira Connect Frameworks on January 31, 2027 and advises vendors to migrate their apps to Jira Forge.
To meet these requirements, ConfigCat developed a new Forge-based ConfigCat Feature Flags Jira app.

:::info Development in progress
The development of the Forge app is currently in progress and not available yet.

The new version of the app will be available before the Connect Framework's EOS. For the exact release date, check the <a href="https://trello.com/b/8gYunIb6/configcat-public-roadmap" target="_blank">ConfigCat Public Roadmap</a>.
:::

## Configuration
### Authorization
<Steps>
    <Step>
        Navigate to any Issue on your Jira board.
    </Step>
    <Step>
        Open the **ConfigCat Feature Flags** Issue Panel or the **ConfigCat Feature Flags** Issue Context section.
    </Step>
    <Step>
        Click **Authorize**.
    </Step>
    <Step>
        Follow the Atlassian authorization steps to authorize ConfigCat in Jira. Click **Configure access**.
    </Step>
    <Step>
        In the opened window, inspect the required access by ConfigCat and click **Continue**.
    </Step>
    <Step>
        In the ConfigCat authorization window, click the **Allow Access** button to complete the authorization.
    </Step>
    <Step>
        After successful authorization, you will be redirected back to the Issue.
    </Step>
</Steps>

:::info
Every Jira user must authorize ConfigCat in Jira who wants to use the ConfigCat Feature Flags App.
:::

### Revoke Authorization
<Steps>
    <Step>
        Navigate to **Account Settings** in Jira.
    </Step>
    <Step>
        Select the **Connected Apps** tab.
    </Step>
    <Step>
        In the **Atlassian third party account access** section, click **Revoke** next to ConfigCat.
    </Step>
</Steps>

### Enable ConfigCat Feature Flags Issue Panel
<Steps>
    <Step>
        Navigate to any Issue on your Jira board.
    </Step>
    <Step>
        If the **ConfigCat Feature Flags** Issue Panel is not visible, click the **View app actions** button under the Issue summary, and select **ConfigCat Feature Flags** in the dropdown.
    </Step>
    <Step>
        Admins can enable the **ConfigCat Feature Flags** Issue Panel for all users in the project. To do this, select the **Show for all work items** option in the panel **Actions** menu.
    </Step>
</Steps>

## Usage

### Linking existing feature flags

<Steps>
    <Step>
        Navigate to any Issue on your Jira board.
    </Step>
    <Step>
        Open the **ConfigCat Feature Flags** issue context.
    </Step>
    <Step>
        On the **Link existing** tab, select a ConfigCat Product, Config, Environment, and Feature Flag to be linked to your Issue.
    </Step>
    <Step>
        When linked, you can manage the selected feature flag from this Issue.

        <video className="video" controls muted>
          <source src="/docs/assets/jira/link-existing.mp4" type="video/mp4"/>
          Your browser does not support the video tag.
        </video>

    </Step>
</Steps>

### Creating new feature flags

<Steps>
    <Step>
        Navigate to any Issue on your Jira board.
    </Step>
    <Step>
        Open the **ConfigCat Feature Flags** issue context.
    </Step>
    <Step>
        On the **Create and Link** tab, select a ConfigCat Product and Config where you want to create the feature flag.
    </Step>
    <Step>
        Set up your feature flag.
    </Step>
    <Step>
        Select which environment you would like to link to this item.
    </Step>
    <Step>
        When linked, you can manage the selected feature flag from this Issue.

        <video className="video" controls muted>
          <source src="/docs/assets/jira/create-and-link.mp4" type="video/mp4"/>
          Your browser does not support the video tag.
        </video>
    </Step>
</Steps>

### View and Edit linked feature flags

<Steps>
    <Step>
        Open an Issue on your Jira board with a linked feature flag.
    </Step>
    <Step>
        See the linked feature flags in the **ConfigCat Feature Flags** issue section.
    </Step>
    <Step>
        You can manage the selected feature flag from this Issue.
    </Step>
    <Step>
        You can add new Targeting Rules or Percentage Options to Feature Flags.
    </Step>
    <Step>
        You can add new Targeting Rules with User, Segment or Prerequisite Conditions with a large selection of Comparators.  [Read more about Targeting.](../targeting/targeting-overview.mdx)
    </Step>
    <Step>
        You can remove Targeting Rules as well.

        <video className="video" controls muted>
          <source src="/docs/assets/jira/edit-ff.mp4" type="video/mp4"/>
          Your browser does not support the video tag.
        </video>
    </Step>
</Steps>

This app doesn't implement the **Releases - Create/Connect feature flag** action. Instead, you can create or link
feature flags from the ConfigCat Feature Flags section below the Details section of the Issue.
